# 🧮 Calculator

## OIBSIP Web Development Internship — Level 2 Task 1

A fully functional browser-based calculator built using **HTML5, CSS3, and Vanilla JavaScript**.

The calculator supports basic arithmetic operations, decimal numbers, operator chaining, error handling, and keyboard input.

---

## 📌 Project Overview

This project demonstrates fundamental frontend development concepts by creating an interactive calculator without using external frameworks or libraries.

The calculator allows users to:

- Enter numbers from 0–9
- Enter decimal values
- Add numbers
- Subtract numbers
- Multiply numbers
- Divide numbers
- Chain operations
- Delete the last entered character
- Clear the calculator
- Calculate results
- Use keyboard input
- Handle division by zero

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

No frameworks or external JavaScript libraries are used.

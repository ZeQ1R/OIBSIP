# 🧠 Albert Einstein Tribute Page

## OIBSIP Web Development Internship — Level 2 Task 2

A responsive tribute page dedicated to Albert Einstein, one of the most influential physicists in modern history.

The project was created using HTML5 and CSS3 with a focus on visual design, responsive layouts, typography, and structured content.

## 📌 Project Overview

The page presents a short biography of Albert Einstein, important moments from his life, his scientific achievements, and his lasting influence.

The website includes:

- Hero section
- Prominent portrait
- Biography section
- Key achievements timeline
- Quote section
- Legacy section
- Responsive navigation
- Footer and source information

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

No JavaScript is required.

## ✨ Features

### Hero Section

The hero section contains:

- Albert Einstein's name
- His lifetime dates
- A one-line tagline
- A prominent image
- Navigation links
- Call-to-action button

### Biography

The biography section contains original paraphrased content covering Einstein's:

- Early life
- Education
- Scientific career
- 1905 papers
- Relativity theories
- Nobel Prize
- Public influence

### Timeline

Important moments in Einstein's life are displayed as styled cards:

- 1879 — Born in Ulm
- 1896 — Studies in Zurich
- 1905 — Miracle Year
- 1915 — General Relativity
- 1921 — Nobel Prize
- 1955 — Death and lasting legacy

### Quote

A dedicated quote section presents a notable quotation attributed to Einstein.

### Legacy

The final section discusses Einstein's continuing influence on physics and scientific thinking.

## 🎨 Design

The website uses multiple visual themes:

- Dark charcoal
- Warm cream
- Light beige
- Gold accent color

Two font families are used:

- **Playfair Display** — headings and quotations
- **DM Sans** — body text and interface elements

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries adjust the layout, typography, image size, navigation, and timeline cards for smaller screens.
